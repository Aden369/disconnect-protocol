# 四方实现与接口 v0.5

当前规则：[game-rules.md](game-rules.md)，实现位于 `src/thuai10/fourway/`。历史双人接口见 [implementation-notes-v0.2.md](implementation-notes-v0.2.md)。

## 核心

`FourWayGame.step` 接受 `p0..p3` 字典或四整数列表。先基于四方旧状态计算掩码，再执行全部动作，推进最多 4 tick（2 秒）。每 tick 同时结算攻击/移动/技能/过载，淘汰清理后检查最后存活者。

资源只在动作成本、生产限制和收入中使用。胜负分支不读取资源或中继控制时长。截止多人存活判平，保留各方淘汰 tick 供排名分组。

## 41 动作

0 WAIT；1–4 四兵种生产；5 磁轨炮；6 固定干扰；7 修墙；8 修核心；9 科技；10–13 选择进攻对象；14–22 信号；23–31 制导导弹；32–40 屏蔽弹。技能九宫按世界坐标 `y=4,14,24`，每行 `x=4,14,24` 排列。

## 固定观测

Schema：`thuai10-fourway-obs-v0.5`，全部 float32，总维度 2681。各策略看到全信息世界坐标；`public` 包含观察者编号，不混用双人左右镜像。

| 键 | 形状 | 内容 |
| --- | --- | --- |
| public | (5,) | 观察者、tick、步数、过载标记、下一个实体 ID |
| companies | (4,12) | 存活、能量、目标方、科技、维修次数、四技能冷却、淘汰时间/标记、核心 HP |
| units | (4,12,20) | 固定单位槽：类型/生命/位置/出生、攻移冷却、自主目标、在线/屏蔽、ID、空军标记、已收信号 ID/目标/期限 |
| structures | (4,38,10) | 6个内部设施候选格（含总部）、32城墙：存在、类型、生命、位置、门、冷却、出生和 ID |
| nodes | (4,7) | 中继坐标、归属、占领进度及所属方、对本方连通/受扰状态 |
| signals | (4,6) | 信标存在、坐标、期限、生效与 ID |
| clouds | (4,6) | 每方 EMP 存在、坐标、期限及 ID |
| projectiles | (4,2,9) | 每方导弹/屏蔽弹：存在、起终点、落地剩余、锁定、信标/弹体 ID |

结构体槽按固定建造位置对应，单位槽存活期间稳定，死后复用；不存在对象为零。中继中立归属/进度方原始值为 -1，归一化后为 -1/3。当前地图固定为 29×29；随机地图或自由建造需要升级观测 schema。

`FourWayEnv` 返回四固定键观测/奖励/标志，`agents` 列出对局未结束时的未淘汰方，终局为空。淘汰奖励 -1 只在淘汰发生时发放，终局不重复扣分；唯一胜者 +1，平局存活者 0。全局自然终局或淘汰设置 terminated，truncated 恒 False。

## 命令、网络与导弹

网络从存活且未被干扰的总部扩展到己方连通中继，再由在线无人机接力；总部受扰时本方全网离线。屏蔽区中的单位/中继离线，但单位继续自主战斗。

信号发射需至少一个联网单位，落点不要求网络覆盖；每方同时一个信标，其有效性只取决于期限及落点受扰状态。信号采用一次上传：单位接收一个信标 ID 后保存目标与期限；离网继续旧命令，单位或目标遭干扰时取消该临时命令，不重新接受同一信标。新信标可重新指挥。制导导弹始终追踪发射时的原信标 ID；屏蔽、到期或被新信标替代都会永久失锁，落点固定、伤害降低。

渲染接收当时网络连线、弹体、云、攻击目标与事件。3D 插值只改变播放表现，不能改变结算、命中或胜负。

## 回放与版本

Schema：`thuai10-fourway-replay-v0.5`。保存完整配置、seed、四方动作、逐步 SHA-256 与结局。哈希包含核心状态、冷却、命令、弹体、云和下一个 ID；不包含纯渲染表现。

通用 `thuai10.core.replay.verify` 根据规则版本路由到四方校验器；旧 v0.1/v0.2 回放继续走旧逻辑。默认 HTTP 创建四方对战，旧 human/watch 仅用于历史调试。

## v0.4 历史兵种变更

该历史版本使用 `configs/balance-v0.4.json`；当前默认配置见下节。无人机掩码检查每方2架上限，`armed=false` 禁止所有攻击（含科技加成），`capture=false` 排除占领/争夺；狗与破城机 `anti_air=false`。机甲和炮塔对空射线越墙。无人机默认跟随攻城/机甲部队、屏蔽时回总部；有效信号仍可改变部署。观测形状保持 v0.3，回放协议升级 v0.4；历史 v0.3 配置缺省字段恢复原有行为。

## v0.5 地图和防御

默认配置改为 `configs/balance-v0.5.json`。地图29×29，基地9×9，墙内7×7，四类防御设施真实结算。结构观测扩大到38槽、类型扩展为6种，坐标除以地图边长减一；观察协议v0.5，2681维。旧回放仍按其原始配置运行，历史观测保留21结构槽。迫击炮范围伤害在同tick同步伤害队列内结算，弧线仅是射击表现，不增加隐藏飞行时间。
