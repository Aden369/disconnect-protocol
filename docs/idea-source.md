## 原文中的杨坤烨方案

> 游戏背景：未来时代，AI快速发展，几家AI公司控制了世界，相互争夺领地。
>
> 游戏机制：每回合分为构建、布局、维修与进攻回合。构建分为科技、军备、防御。升级科技可以提高防御设施、兵种、战略打击的等级。选择建造军备可以解锁更多兵种（无人机、机器狗、机器人、攻城车、信息干扰部队……），并提高生产兵种的速度，每个兵营可以选择生产几个兵种。选修建防御建筑可以建更多种类建筑（加农炮、激光、信息屏蔽器……）。布局回合可以调整建筑的布局，但是只允许进行一定步数的调整。维修会修复上次进攻中受损的设施。进攻回合可以选择在周围一定范围内布置兵种，兵种根据一定逻辑攻击城池或者与其他阵营兵种交战。期间可以通过发射信号弹指挥兵种移动并攻击目标，也可以发射信号屏蔽弹，战略轰炸或者强化弹影响战局。被攻陷大本营的阵营被判失败，变为可占领的格子，可以被其他势力占领。
>
> 胜负判定：最终存活下来的阵营获胜。

以上仅规范了标点和省略号，未加入其他成员的方案。原文未给出单局时间、地图、成本、伤害、接口或结算细则。

## v0.1 / v0.2 首版取舍（历史）

| 原始方向 | 首版规则 | 目的 |
| --- | --- | --- |
| 多家公司互争领地、最终存活者胜 | 两家公司对抗；摧毁总部立即获胜 | 降低多智能体训练和 demo 理解成本 |
| 四阶段循环 | 保留构建、布局、维修、进攻，最多六轮 | 保留节奏，限制局长 |
| 科技、军备、防御三条建设方向 | 单层科技、兵营及三种建筑 | 避免长科技树吞掉短局决策时间 |
| 多种兵种 | 机器狗、机器人、攻城车 | 分别承担抢点、作战、攻城职责 |
| 有限布局调整 | 每轮至多移动或交换一次建筑 | 布局有作用，动作空间仍有限 |
| 战后维修 | 花资源修一栋建筑，每轮一次 | 保留经济与防御取舍，限制无限恢复 |
| 自动战斗和信号弹指挥 | 部署任务稳定的自动寻路与攻击；信号弹临时改变全军目标区域 | 避免逐单位高频微操 |
| 屏蔽弹、轰炸、强化弹 | 首版提供信号弹和小范围轰炸 | 先形成清晰的干预与反制闭环 |
| 失败阵营地块可被占领 | 双人终局不再执行失败地块占领 | 双人场景没有剩余争夺方 |

中央两个资源节点、全信息观测、固定时间步、六轮上限和超时评分是本次新增建议，不是原文已有机制。无人机、干扰部队、激光、屏蔽器、强化弹和多阵营模式保留为扩展，首版不承诺实现。

工程参考：[THUAI9 README](https://github.com/eesast/THUAI9#readme)，只借鉴逻辑、选手接口、界面、回放的职责分离。本次不沿用上一届游戏规则或强制使用其技术栈。
