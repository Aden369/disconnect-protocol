# v0.5 规则与实现一致性核对

2026-10-11。核对对象为当前默认四方模式：`configs/balance-v0.5.json`、`src/thuai10/fourway/game.py`、`env.py`、`session.py`、HTTP默认创建模式及现有测试。旧v0.1–v0.4文档和评测保持历史记录含义。

## 结论
当前29×29地图、9×9基地、7×7内部空间、四兵种、四类防御设施、所有成本/HP/射程/冷却、41个动作、过载公式和最后存活判胜与代码一致。主规则与v0.5版本副本已同步修正以下歧义；游戏机制和数值没有改变。

## 修正明细

| 项目 | 当前实现及修正文案 | 依据 |
| --- | --- | --- |
| 淘汰排名 | 保存淘汰tick，可在外部生成并列分组；没有直接输出排名表 | `Company.eliminated_tick`、`frame`、`snapshot` |
| 淘汰后技能 | 信标移除，后续tick在途导弹可能失锁；弹体/云保留，但终局后不再推进 | `resolve_tick`、`step` |
| 初始资源 | 140能量之外免费配发部队、总部、初始防御与城墙 | `reset` |
| 无人机分流 | 只有一名地面部队时两架会共同跟随；至少两名时选不同对象 | `movement_goal` |
| 机甲护卫 | 是战术用途，程序实际执行优先敌军/总部推进，没有独立自动护送指令 | `movement_goal`、目标选择 |
| 攻击与移动 | 有可攻击目标时先攻击/装填，不同时移动；同类优先级按距离、相对阵营、出生tick、ID选目标 | `resolve_tick` |
| 格子占用/射线 | 部队可同格，建筑不可堆叠；无人机越墙但仍绕建筑；己方墙不遮挡己方射线，迫击炮越墙仅对地 | `next_step`、`shot_clear`、攻击过滤 |
| 重建/科技 | 磁轨炮/干扰器固定格可重建；迫击炮/防空塔和已毁城墙无重建动作；三类防御炮塔科技均+4，地面兵对建筑伤害不增 | `mask`、`execute`、伤害队列 |
| 总部受扰 | 本方全网离线；远端单位未受扰也无法保持连接 | `compute_network` |
| 信标生效 | 发射需至少一个联网单位；可落任意九宫，不需单位驻守/落点联网；已有信标不会仅因总部断网失效 | `mask`、`beacon_active` |
| 信标替换 | 每方一个信标，新信标替换旧的；离网单位已保存的旧命令可持续至原期限 | `execute`、`receive_commands` |
| 导弹截止 | 发射tick+8≤360：176秒允许、178秒禁止；提前终局不继续落弹 | `mask`、`resolve_tick` |
| 结算位置 | 普攻及迫击炮名单移动前确定；导弹按移动后位置判定。迫击炮无额外弹道飞行时间 | `resolve_tick` |
| 训练接口 | 本地并行接口，41动作编号范围；2681维float32字典，建筑38槽；终局agents为空，truncated恒False，未注册Gym/PettingZoo | `env.py` |
