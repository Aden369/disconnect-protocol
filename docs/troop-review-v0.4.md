# 兵种与无人机平衡复核 v0.4

## 修正
旧版无人机同时越墙、攻击建筑、占点、通信，地面兵职责不清。现版本改为无武装支援，45HP/45能量，上限2架（含初始1架）。不占领/争夺，默认跟随地面单位；机甲和炮塔可以跨墙防空，EMP切断链路。狗负责中继，机甲优先敌军并防空，破城机优先建筑但不能防空。

UI增加四兵种说明、职责标签，点击仍显示真实当前目标/通信状态。地面模型适度放大。

## 验证
- 100项测试通过，新增无人机上限/占点排除、科技不解锁武器、地面对空限制与跨墙防空、跟随/EMP返航、历史v0.3回放兼容测试。
- 24种策略排列全部完成：破墙8胜、导弹8胜、堡垒4胜、电子战0胜，4平局；平均168.67秒、最长172秒。
- v0.3排列结果为导弹16胜、堡垒4胜、4平局。比较同时包含兵种与电子战基线调整，不能单独归因于无人机参数。
- 结果 `results/fourway-scripts-v0.4.json`，回放 `results/fourway-replay-v0.4.json`。

## 尚未解决
电子战基线仍弱，多数对局在过载阶段结束。这次限定修正兵种职责与无人机越墙收益，不宣称完成整体竞技平衡。后续需增强前中期破墙进攻、电子战与护卫配合，再扩大评测。
