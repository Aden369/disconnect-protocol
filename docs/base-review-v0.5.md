# 地图与基地扩展验收 v0.5

## 范围
地图由21×21扩大到29×29；基地由5×5扩大到9×9，墙内可用空间由3×3扩大到7×7。每方32段城墙、两座授权门，四方总部和设施按90度旋转。地图、节点、九宫技能、部署点、通信范围与归一化坐标同步更新。

每座基地初始拥有磁轨炮、电磁迫击炮、防空激光塔、干扰阵列。迫击炮范围伤害排除空军和友军，可越墙；防空塔只射击无人机。设施可被摧毁、随总部淘汰清理。迫击炮与防空塔本版没有重建动作，磁轨炮可增建、干扰阵列可重建。

## 验证
- 全套105项pytest通过，最终观测冷却归一化调整后四方28项再次通过；Ruff通过。
- 新增基地旋转/空间不重叠/设施墙内、迫击炮范围及冷却、防空目标/射线、38个固定建筑观测槽、新旧回放兼容测试。
- 24种策略排列全部完成：导弹8胜、破墙4胜、12平局；平均170.33秒，最长172秒。416段城墙在战斗中被摧毁。
- 12局随机合法动作对战全部完成，6胜/6平，最长166秒；包含重建、维修与技能组合。
- v0.3、v0.4回放通过兼容测试，v0.5回放85步哈希验证通过。
- 当前窄窗口已实测完整显示四座基地，默认视角根据地图尺寸与画布比例适配；控制台无错误。建筑可点击追踪，UI显示兵与设施数量。
